# Public evaluation artifacts

This directory contains small evidence bundles reviewed for inclusion with the
source repository. It is separate from `evaluation/results/`, whose historical
study files can include source-derived annotations or predictions and are
excluded from the public release.

Each bundle must contain its own scope statement, third-party data provenance and
terms, validation result, and checksums. Adding one here does not clear any other
historical result for publication.

- [`frame_format_tokens/qwen38_27b/2026-09-09/`](frame_format_tokens/qwen38_27b/2026-09-09/):
  matched-frame Qwen processor visual-token census and Figure 3 evidence.
